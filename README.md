# Uptime Monitor

A full-stack uptime monitoring platform that checks websites on a schedule, tracks incidents, sends email alerts, and provides public status pages.

> Status: in development

## Features

- [x] Express server with env validation and centralized error handling
- [ ] Authentication
- [ ] Monitor management
- [ ] Scheduled checks and UP/DOWN detection
- [ ] Incidents and email alerts
- [ ] Public status page
- [ ] React dashboard

## Tech Stack

Backend: Node.js, Express, MongoDB (Mongoose), Zod
Frontend: React, Tailwind CSS (coming soon)

## Run the backend

cd server
npm install
copy .env.example to .env and fill in values
npm run dev
